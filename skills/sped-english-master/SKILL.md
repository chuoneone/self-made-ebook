## ⚡ 核心鐵則（絕不妥協的 5 大規範）

### 1. 🔤 字體與字級規範
- **字體**：中文全面使用 **`芫荽` (Iansui)** 字體（備援字體為 `Noto Sans TC` 與微軟正黑體）；英文搭配 `Inter` 或 `Andika`。
- **字級**：**全文內文、題目、填空線、選項一律強制 14 號字** (`Pt(14)`，Word XML `<w:sz w:val="28"/>` 與 `<w:szCs w:val="28"/>`)。
- **大標題**：18 號字粗體；單元標題：16 號字粗體。

### 2. 🤐 文字極簡零廢話與無音標（降載原則）
- **題目直截了當**：開門見山直接給題目與情境，嚴禁長篇大論、囉嗦引導或說教式文字。
- **標題純淨化**：
  - ✅ 正確：`【單元一：How 與 What 選擇題】`、`【單元二：漸進式造句填空】`。
  - ❌ 嚴禁：`【學生練習 2】（微變化：反求原值）` 或 `(高鷹架：挖空最後2步)` 等任何內部解題註解。
- **🚫 符號降載鐵則**：
  - **一律不附 KK 音標**（避免符號造成特教學生視覺混淆與記憶負擔）。
  - 題幹不給洩題提示括號。

### 3. 📄 概念單元獨立換頁 (Page Breaks)
- 學習單每換一個文法單元（例如：文法一 How/What ➔ 文法二 天氣時態），**必須自動插入分頁符號 (`doc.add_page_break()`)**，嚴禁多個文法擠在同一頁造成學生焦慮。

### 4. 🎨 皮克斯 3D 視覺與極致輕量化 (Images)
- **風格**：一律採用「**皮克斯 3D 動畫風格 (Pixar 3D Style)**」高質感溫暖情境圖。
- **畫面純淨**：純情境畫面，**嚴禁任何無意義英文字或亂碼文字**（若有文字必須為繁體中文）。
- **輕量化限制**：一律轉為 **WebP 格式**，每張圖片檔案大小嚴格控制在 **40KB ~ 50KB 左右**，避免 GitHub 存儲容量爆掉。

### 5. 🎛️ 雙版本自動產出
- 每次生成 Word 學習單或小考卷，一律自動生成 **學生練習版** 與 **教師解答版**（含粗體紅色劃線答案標註）。

### 【階段二：文法核心學習單、課堂簡報與線上測驗】

#### 1. 紙本學習單（Word 學生練習版 + 教師解答版）
- **版面配置**：直式清爽閱讀版面（非雙欄，留足書寫空間）。
- **結構標準**：同出一份學習單，每種文法焦點固定包含以下兩大題型：
  - **Part 1：極簡選擇題（每文法固定 10 題）**
    - 二選一或三選一語法焦點對比（如 `How vs What`、`be 動詞`、`現在式 vs 過去式`）。
    - 題幹乾淨無提示括號，選項隨機排序。
  - **Part 2：漸進式挖空填空題（每文法固定 5 題，Scaffolded Completion）**
    - 特教降載鷹架，由淺入深：
      - 第 1~2 題：給前半句與情境，只填關鍵核心字（如疑問詞、助動詞）。
      - 第 3~4 題：半句填空（如主詞 + 動詞）。
      - 第 5 題：鷹架引導寫出完整句子。
- **切換文法**：每換一種文法觀念，強制獨立換頁。

#### 2. 課堂投影互動簡報 (HTML)
- **清爽亮色模式 (Light Mode)**：白底黑字、高對比大字級（題目 28px+、選項 22px+）、支援觸控。
- **第 1 頁（美化文法引入）**：純粹優雅的文法重點圖解、例句高亮排版，供老師開場講授。
- **後續頁（逐題互動）**：**100% 完全依照紙本學習單的題目與順序逐題出現**（先 10 題選擇，再 5 題填空），具備點擊遮罩揭曉答案、Web Audio 音效與專注倒數計時。

#### 3. 雙軌線上測驗 (Web Apps)
- **線上選擇測驗 (HTML)**：將學習單 10 題極簡選擇題做成線上測驗，含即時反饋與計分。
- **線上重組句子測驗 (HTML, Sentence Unscramble)**：將學習單 5 題填空的完整句子轉為單字積木點選重組（支援積木點選、流暢拖曳、雙語發音、Confetti 慶祝彈窗）。
- **獨立運行**：產出之 HTML 檔案為單一獨立離線檔案，可直接開瀏覽器使用。

## 🌟 【英文備課電子書】最新黃金標準模版（全套 HTML 規格）

## 📖 講義核心靈魂：從課文（Dialogue & Reading）提煉文法與文本重點（Contextual Grounding）

講義絕非孤立生硬的文法題庫，而是**「100% 依託課文故事脈絡」的情境探索講義（以國二 Unit 2 為典範）**：
1. **絕不脫離課文憑空造題**：
   - 收到備課教材時，第一步必須精讀課文對話（Dialogue）與篇章閱讀（Reading），提煉出該課的核心人物、生活情境與情節衝突。
   - 所有文法焦點、圖解口訣、任務造句、練習題與克漏字，**一律使用課文人物與課文真實情節**，讓學生在熟悉的故事脈絡中自然吸收文法。
2. **文本 ➔ 文法 ➔ 架構的提煉原則（11 頁標準脈絡）**：
   - **P.1 故事起點與視覺錨點**：引入課文對話第一幕（逐句中英對照），並提煉出課文關鍵情境字彙（如生病症狀地圖、天氣圖）與課文故事情境暖身題。
   - **P.2~P.7 三大文法任務**：文法句型必須源自課文台詞（如 Bella 說 `I sent a message to you` 提煉「授與動詞先人後物」；Scott 說 `bring ice cream to me` 提煉「介系詞 to/for 過橋費」；`Why didn't you see a doctor?` 提煉「didn't 原形動詞與 Because/So 因果」）。解題造句全面貫穿課文情境。
   - **P.8 任務四：單字積木重組**：直覺式重組課文關鍵對話與核心句型，免除特教抄寫負擔。
   - **P.9 課文深讀與篇章結構化（雙軌核心）**：
     ① 課文原文採「逐句中英對照」（綠色指示線＋圓潤易讀排版，**嚴禁用旁白簡化竄改課文原文**）。
     ② 底部必須提煉為**「Graphic Organizer 篇章結構對照表」**（例如各國文化療法大 PK、問題與解決策略對照表），上方附 Word Bank 字庫，挖空關鍵單字點擊顯答，訓練特教生看懂文章架構。
   - **P.10~P.11 課文完整語境驗收（免手寫二選一圈選克漏字）**：
     - **P.10 對話克漏字特訓（20～25 題）**：重現課本真實對話情境（Dialogue）。
     - **P.11 篇章克漏字特訓（20～25 題）**：重現課本短文篇章（Reading） ＋ 完課星等認證與教師蓋章處。

### 1. 課堂講義（Coursebook，11 頁獨立 A4）

- **規範**：容器高度嚴格控制在 `1123px`（標準 A4 高度），零溢頁、零切字。
- **頁面結構**：即上述 P.1 至 P.11 由課文文本深度提煉之 11 頁結構。

### 2. 單字隨堂學習單（4 節課，每節嚴格 4 頁，共 16 頁標準 A4，一頁一焦點）

- **核心鐵則**：所有年級（國一、國二、國三）的單字學習單，**一律強制使用此 4 頁標準架構**，嚴格禁止舊版 2 頁或 5 欄擠塞排版。
- **四頁式標準架構（1 頁專注 1 區塊，題目充裕增多、字級 14pt+ 特教友善、題目絕不跨頁）**：
  - **第 1 頁（單字探索與四線格抄寫）**：
    - 雙欄大字卡（`vocab-grid-4page`、`vocab-card-large`，14.5pt 粗體英文、13pt 中文、62×62px 皮克斯 3D WebP 縮圖、🔊 Web Speech 真人發音、跟讀 3 次打勾標籤）。
    - 每個單字卡下方具備寬敞標準的英文四線三格手寫練寫區（`handwriting-guide-large`）。
    - **支援點擊卡片獨立揭曉四線格紅字抄寫範本答案（`.hw-answer-text`）**，亦可隨工具列一鍵全開顯答；學生端 `@media print` 列印時自動隱藏維持純淨練寫線。
  - **第 2 頁（區塊二：聽音連連看 / 圖文配對）**：
    - 題目充裕增多（涵蓋該節 7～10 個全部單字）。
    - 採左右對照配對排版（`match-board-full`）：左欄 🔊 點擊播音按鈕 ＋ 填寫代號括弧 `( [A] )`；右欄為 (A)~(H)/(J) 之「38×38px 圖片 ＋ 英文 ＋ 中文」選項卡片。
    - 點擊左欄題目卡可獨立揭曉紅字代號答案，支援一鍵全開與板書劃線。
  - **第 3 頁（找缺的字母：Missing Letters 補字母拼單字）**：
    - 頂部附清楚的【Word Bank 單字庫】晶片盒（`word-bank-box`、`word-chip`）。
    - 雙欄拼寫卡網格（`spell-grid-full`、`spell-card-full`），54×54px 圖解＋16pt 粗體英文字母＋底線字母挖空槽（`letter-slot` 搭配隱藏紅字 `letter-ans`），點擊即時浮現紅字答案。
  - **第 4 頁（生活語境例句選擇 / 句子實戰 ＋ 完課認證）**：
    - 題目充裕增多（7～8 題真實生活例句與對話，`context-list`、`context-item`）。
    - 每題附繁體中文情境線索，括號二選一圈選（`correct-choice`），點擊顯示紅框紅字答案。
    - 頁面底部配置「🌟 學習自我檢核與完課認證盒（`mastery-cert-box`）」（5 星自我評分、教師簽章與日期）。

### 3. 🚫 嚴禁製作傳統全課單字翻譯手寫考卷

## 🛠️ Python Word 程式碼生成關鍵範本

```python
import docx
from docx.shared import Pt, Inches, RGBColor
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

def set_run_font(run, font_name="芫荽", font_size_pt=14, bold=False, color_rgb=None):
    run.font.name = font_name
    run.font.size = Pt(font_size_pt)
    run.bold = bold
    if color_rgb:
        run.font.color.rgb = color_rgb
    
    # 確保 Word XML 嚴格指定字體與 14 號字
    rPr = run._r.get_or_add_rPr()
    rFonts = OxmlElement('w:rFonts')
    rFonts.set(qn('w:ascii'), font_name)
    rFonts.set(qn('w:hAnsi'), font_name)
    rFonts.set(qn('w:eastAsia'), font_name)
    rFonts.set(qn('w:cs'), font_name)
    rPr.append(rFonts)
    
    sz = OxmlElement('w:sz')
    sz.set(qn('w:val'), str(int(font_size_pt * 2)))
    rPr.append(sz)
    szCs = OxmlElement('w:szCs')
    szCs.set(qn('w:val'), str(int(font_size_pt * 2)))
    rPr.append(szCs)
```
