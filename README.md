## 💡 為什麼需要「自製電子書」？（設計理念）

### 1. 書商資源 vs 自編教材：自編學習單的終極救星
上課使用書商資源時，我們很習慣開著廠商附的電子書，大螢幕一投就能跟學生同步對照。**即使教室沒有昂貴的觸控大螢幕，老師只要拿著普通滑鼠輕輕點擊，也能逐題開解答、畫線圈重點，上課節奏流暢又直觀。**

但是，**如果是老師自己用心編寫的學習單、講義或段考複習卷呢？**  
過去我們往往只能陷入無奈的二選一：
- ❌ **黑板苦抄**：上課時老師要在黑板上辛苦手寫抄題目、畫圖表，耗時又費力。
- ❌ **熬夜做簡報**：備課時明明已經出好學習單了，為了上課講解，還得一題一題複製貼上，大費周章另外重做一份 PPT 簡報！

**現在，「自製電子書」徹底解決了這個痛點！**  
只要把您自編的教材丟給 AI，幾秒鐘就能生成專屬於您的「自製互動電子書」：
- **普通滑鼠點擊就能用**：不用觸控大屏！傳統投影機＋普通滑鼠，點一下題目就亮出紅筆解答，再次點擊就隱藏。
- **徹底告別重做 PPT**：學習單本身就是最好用的教學簡報，省下無數備課時間。

### 2. 視線零時差：學生學習極度直觀，不再迷航
很多時候把學習單改做成 PPT 簡報，排版、字型和學生桌上的紙本完全不同，學生常在「抬頭看簡報」與「低頭找題目」之間迷航，特別對學習障礙或容易分心的學生是沉重負擔。  
這套方案讓**投影螢幕上的自製電子書與桌上紙本 100% 完全同步**，行距、字級、結構完全一致，學生跟課直觀輕鬆、學習成效立竿見影！

## ✨ 核心特色

### 🖨️ 學生紙本列印模式（A4 Print）
- **格式 100% 穩定零跑版**：精確適配標準 A4 邊距，採用 `justify-content: flex-start` 搭配底端頁尾吸附，**徹底告別下方題目遭裁切或多印空白尾頁的困擾**。
- **一鍵純淨輸出**：按下列印（或 `Ctrl + P`）時，智慧樣式會**自動過濾所有解答、工具列與筆跡**，還原為無解答的標準白紙作業／試卷。
- **零干擾提示**：卷面上絕無「點題目秀答案」等操作提示字眼，保證學生看到的卷面最乾淨、專業。

### 🖥️ 課堂大屏／投影教學模式（Classroom Presentation）
- **逐題點擊秀答案**：不論使用**電子白板、大屏觸控、平板手寫或普通滑鼠**，手點或點擊題目任意處，解答即以「紅筆手繪圈選／填入」樣式即時顯現，講解節奏完全由老師掌控。
- **一鍵全開答案**：工具列提供「👁️ 答案」切換鍵，集體對答案或課堂總結時一秒全卷揭曉。
- **多功能懸浮螢光筆工具**：
  - 🟡 **螢光黃**：劃記重點文字，半透明不遮擋字母。
  - 🔴 **紅色**：重點訂正、錯誤圈記。
  - 🔵 **藍色**：文法結構／主角劃記。
  - 🟢 **綠色**：關鍵補充筆記。
  - 提供 **細（4px，預設）、中（10px）、粗（20px）** 三段筆觸，並支援一鍵清除畫記。

## 📦 專屬收錄：5 大雙模式備課電子書核心大師 Skills

本套件將 **5 大雙模式電子書專用 Skills** 完整收錄於 `.claude/skills/` 資料夾，clone 本倉庫、用 AI 助理打開即可使用：

| 分類 | Skill 名稱 | 功能亮點 |
| :--- | :--- | :--- |
| **通用底層** | `self-made-ebook` | 通用雙模式互動 HTML 電子書底層框架、存檔規則與電子書目錄 |
| **國文大師** | `sped-chinese-master` | 國中特教國文備課大師（30 頁雙頁精讀 ＋ 注音田字格 ＋ 句意深究 ＋ 字族文辨析） |
| **英文大師** | `sped-english-master` | 國中特教英文備課大師（**雙支柱：12 頁關卡式文法講義 ＋ 16 頁四頁式單字手冊**） |
| **數學大師** | `sped-math-master` | 國中特教數學備課大師（觀念解題原則 ＋ 1-2 適性 5 階漸進式填空鷹架） |
| **影音大師** | `sped-youtube-master` | YouTube 影音轉 4 頁 B-D-A 階梯式雙模式電子書（動態 QR Code ＋ 時間軸尋寶） |

> 🎚️ **不是特教老師也能用**：每次製作前 AI 會先問學生程度（💡 特教學障／📘 基礎待補強／📗 普通班／📕 進階拔尖）。上表的頁數架構是特教版標竿；選普通班或進階班時，會自動縮短鷹架、減少頁數、加深題型。想固定預設程度，可修改 `AGENTS.md` 的「教師的個人偏好」。

## 🚀 第一次使用（3 步驟）

### 1. Clone 倉庫
```bash
git clone https://github.com/chuoneone/self-made-ebook.git
```

### 2. 用你的 AI 助理打開這個資料夾
Claude Code、Codex、Cursor、Antigravity、Gemini CLI 都可以。**不需要另外安裝**：Claude Code 會自動載入 `.claude/skills/`，其他 AI 助理會讀 `AGENTS.md`。

### 3. 把教材交給它
> 「這是我這週的學習單，請幫我做成自製電子書。」

完成後，成品會存到 `ebook/<科目>/`，並自動登記到目錄。**用瀏覽器打開 `ebook/index.html`，就能看到你做過的所有電子書。**

### 電子書目錄 `ebook/index.html`
- 依科目、年級篩選，可搜尋書名或標籤，按建立日期排序。
- 小考系列（第一次、第二次……）會合併成一張卡片，每次小考各有一顆按鈕。
- 內建 3 本範例電子書，可用「顯示範例電子書」開關隱藏；不需要時，直接請 AI 助理刪掉 `demo: true` 的紀錄。
- 目錄資料在 `ebook/index.html` 的 `<script id="ebook-catalog">` JSON 裡。如果有電子書漏登記，可以執行：
  ```bash
  node .claude/skills/self-made-ebook/scripts/rebuild-index.mjs ebook
  ```
- 不想把自己的電子書推上 GitHub？取消 `.gitignore` 最後兩行的註解即可。

### 更新到最新版
在這個資料夾執行一次即可，Skills 和目錄頁模板會一起更新（你自己做的電子書不受影響）：
```bash
git pull
```

## 💡 該用哪種方式？（推薦：一律在這個資料夾裡做）

| | ✅ 在這個資料夾裡做（推薦） | 全域安裝（進階） |
| :--- | :--- | :--- |
| 安裝 | 不用安裝，clone 即可 | 要另外跑安裝腳本 |
| 電子書目錄 | 所有電子書集中在同一個 `ebook/index.html` | 在哪個資料夾做就存在哪，會有好幾個目錄頁 |
| 更新 | `git pull` 一次完成 | `git pull` 後還要**重跑安裝腳本**，否則會用到舊版 |
| 支援的 AI 助理 | Claude Code（`.claude/skills`）＋其他讀 `AGENTS.md` 的助理 | 安裝腳本只支援 Claude Code 與 Antigravity |
| 換電腦／備份 | 電子書與規格都在同一個 git repo | 電子書分散各處 |

這套工具的核心是「持續累積很多本、用一個目錄統一管理」，所以**建議大多數老師直接在 clone 下來的資料夾裡做電子書**。

### （進階）全域安裝：在任何資料夾都能做電子書
適合教材本來就分散在不同資料夾（例如每學期、每班一個資料夾），並且能接受「一個資料夾一個目錄頁」的老師。成品會存到當下資料夾的 `ebook/`，第一次使用時會自動建立目錄頁。

> ⚠️ **不要同時保留兩份**：如果已經全域安裝，又在這個 repo 資料夾裡使用，AI 助理會同時看到全域與資料夾內兩份同名 Skills；全域那份若沒更新，就可能套用舊規則。請擇一：
> - 刪除全域那份，只在這個資料夾裡使用（推薦）；或
> - 每次 `git pull` 後都重跑一次安裝腳本，讓全域版本保持最新。
>
> 全域 Skills 的位置：Claude Code 為 `~/.claude/skills/`，Antigravity 為 `~/.gemini/config/skills/`。

Windows：
```powershell
powershell -ExecutionPolicy Bypass -File scripts/install-skills.ps1
```
macOS / Linux：
```bash
bash scripts/install-skills.sh
```
可加參數只裝某一個 AI 助理（`claude` / `antigravity`），或指定專案資料夾，詳見腳本開頭的說明。

## 📖 常用指令與觸發方式

在對話中直接以自然語言下達指令即可自動調用：

- **通用電子書**：「這是我這週的備課資料，請幫我做成自製電子書。」
- **國文備課電子書**：「幫我備國文電子書，課文是……」
- **英文文法講義**：「幫我做英文文法講義，單元是……」
- **英文單字手冊**：「幫我出這 30 個單字的 16 頁四頁式單字隨堂手冊」
- **數學漸進式電子書**：「幫我做數學電子書，單元是一元一次方程式……」
- **YouTube 影片轉講義**：「幫我把這個 YouTube 影片做成 4 頁雙模式電子書：[網址]」
- **整理電子書目錄**：「把範例電子書從目錄移除」、「幫我檢查目錄有沒有漏登記的電子書」
