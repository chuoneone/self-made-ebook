# Interactive Lesson Worksheet (雙模式教學互動學習單)

> 各科備課講義與學習單產生器：支援 A4 純淨學生卷列印，以及課堂投影滑鼠互動（點擊秀答案、多色螢光筆劃記）。

本專案是一個專為**中小學各科教師**與**AI 程式輔助教學**設計的講義產生規範與範本。特別針對「**教室無觸控螢幕、僅能使用滑鼠操作投影機**」的教學現場進行深度最佳化，同時完美相容學生紙本測驗需求。

---

## ✨ 核心特色

### 1. 雙模式無縫切換（Dual-Mode）
- 🖨️ **學生紙本列印模式（A4 Print）**：
  - 符合標準 A4 邊距與跨頁分頁（`@page { size: A4; margin: 12mm 15mm; }`）。
  - 按下列印或 `Ctrl + P` 時，自動隱藏所有解答、工具列與畫筆筆跡，還原為乾淨白紙學生卷。
  - **零干擾文字**：絕不印出任何「點題目秀答案」等操作提示。
- 🖥️ **教室投影互動教學模式（Classroom Presentation）**：
  - 專為滑鼠操作設計，無須觸控螢幕或外接繪圖板。
  - **逐題揭曉**：滑鼠點擊題目任意處，答案即時以紅筆圈選／填入樣式顯現或隱藏。
  - **一鍵全開**：工具列提供「👁️ 答案」按鈕，快速切換全卷解答。

### 2. 內建極簡懸浮工具列與畫筆
- **4 種筆觸顏色**：
  - 🟡 螢光黃（預設，半透明底色，劃線不遮擋文字）
  - 🔴 紅色（重點訂正、圈選錯誤）
  - 🔵 藍色（主詞或文法結構標記）
  - 🟢 綠色（動詞或補充筆記標記）
- **3 段筆觸粗細**：細（4px）、中（10px）、粗（20px 螢光寬筆）。
- **一鍵清除**：輕鬆清空當前所有畫記，投影片隨時保持整潔。

### 3. 特教與認知負荷友善排版（Special Ed & Low Cognitive Load）
- 採用中英文經典印刷字型（英文 `Times New Roman`、中文 `標楷體`）。
- 內文鎖定清晰 **14pt** 字級與適度行距，降低閱讀障礙學生與後排學生的視覺焦慮。
- 選擇題括弧固定對齊，選項垂直堆疊排列，排版穩定不跳行。
- 連連看題型內建 SVG 動態虛線連線，點擊即自動平滑連接至目標歸納盒。

## 🚀 使用方式

### 方法一：作為 Antigravity AI Skill 使用（推薦）
將此目錄安裝至全域或專案中：
1. **全域安裝**：複製至 `~/.gemini/config/skills/interactive-lesson-worksheet`
2. **專案安裝**：複製至專案根目錄 `.agents/skills/interactive-lesson-worksheet`

在對話中直接提供教材並呼叫：
```text
這是我這週的國中英文/數學備課資料，請幫我製作成雙模式互動講義
```
AI 將自動依據 `SKILL.md` 規範，將知識點解構為 5 階段鷹架闖關關卡並產出單一獨立 HTML。

### 方法二：直接使用範本（手動編輯）
1. 複製 `resources/template.html`。
2. 以任意文字編輯器或 VS Code 開啟，在 `<div class="pages-container">` 內填入題目內容。
3. 以瀏覽器（Chrome、Edge、Safari 等）開啟即可開始投影教學或直接列印。
