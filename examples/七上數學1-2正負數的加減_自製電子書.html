💡 1-2 核心重點速記：
  • 同號相加：符號相同，數字相加，結果保持同號（例如：(－2)＋(－3)＝－5）。
  • 異號相加：正負抵銷，以絕對值較大者的符號為結果符號，大數減小數。
  • 減法法則：「減去一個數，等於加上它的相反數」（例如：a－b ＝ a＋(－b)）。
  • 去括號法則：括號前是「＋」，拆括號符號不變；括號前是「－」，拆括號正負相反！
  • 兩點距離：數線上 A(a)、B(b) 兩點距離為 AB ＝ |a－b| ＝ 大數－小數。
  • 中點坐標：A(a)、B(b) 的中點坐標 M ＝ a＋b2。

九、與定點等距離的坐標
1. 數線上有 A、B 兩點，其中 A 點的坐標為 6，且 AB ＝4，求 B 點的坐標。
【計算空間】
B 點在 A 點右方或左方：
\(6 + 4 = 10\) 或 \(6 - 4 = 2\)
答： 2 或 10
2. 數線上有 C、D 兩點，其中 C 點的坐標為 7，且 CD ＝8，求 D 點的坐標。
【計算空間】
D 點在 C 點右方或左方：
\(7 + 8 = 15\) 或 \(7 - 8 = -1\)
答： －1 或 15
3. 數線上有 E、F 兩點，其中 E 點的坐標為－1，且 EF ＝7，求 F 點的坐標。
【計算空間】
F 點在 E 點右方或左方：
\((-1) + 7 = 6\) 或 \((-1) - 7 = -8\)
答： －8 或 6
4. 數線上有 G、H 兩點，其中 H 點的坐標為－10，且 GH ＝6，求 G 點的坐標。
【計算空間】
G 點在 H 點右方或左方：
\((-10) + 6 = -4\) 或 \((-10) - 6 = -16\)
答： －16 或 －4

十、求中點坐標
1. 若 A 點坐標為 4，B 點坐標為 12，M 點為 A、B 兩點的中點，求 M 點坐標。
【計算空間】
中點公式：\(M = \frac{A + B}{2}\)
\(M = \frac{4 + 12}{2} = \frac{16}{2} = 8\)
答： 8
2. 若 A 點坐標為－8，B 點坐標為 14，M 點為 A、B 兩點的中點，求 M 點坐標。
【計算空間】
中點公式：\(M = \frac{(-8) + 14}{2}\)
\(M = \frac{6}{2} = 3\)
答： 3
3. 若 A 點坐標為－5，B 點坐標為－15，M 點為 A、B 兩點的中點，求 M 點坐標。
【計算空間】
中點公式：\(M = \frac{(-5) + (-15)}{2}\)
\(M = \frac{-20}{2} = -10\)
答： －10
4. 若 A 點坐標為－17，B 點坐標為 17，M 點為 A、B 兩點的中點，求 M 點坐標。
【計算空間】
中點公式：\(M = \frac{(-17) + 17}{2}\)
\(M = \frac{0}{2} = 0\)
答： 0
